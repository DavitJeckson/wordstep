# 词阶（Word Step）

**词阶（Word Step）** 是一款本地优先、纯原生前端单文件（`index.html`）实现的英语单词学习与查词应用。无需构建步骤与后端服务，所有词书缓存、学习进度、测验成绩和个人设置均保存在浏览器的 `IndexedDB` 中，打开即可使用。

- **在线体验**：https://davitjeckson.github.io/wordstep/

---

## 核心功能

- **每日三步闭环学习**
  每天按「近期批次复习 → 今日新词精读 → 双轮巩固测验」的节奏推进。复习阶段采用近期批次策略（优先复习最近一次学习日期学过的单词），测验包含「第一轮 · 认词（四选一）」与「第二轮 · 拼写（中文提示拼写）」，答错的词会在当轮末尾自动加练并记入巩固列表。
- **立体词条与语音朗读**
  词条详情涵盖英/美音标与发音、词书内嵌录音（可选）、核心中文释义、Markdown / AI 深度用法解析、常用短语、双语例句、近义词、形似与易混词、词根词源及同源词。短语和例句支持通过浏览器本地 TTS（`Web Speech API`）以 `0.9x` 语速朗读跟读。
- **跨词书查词与文中点查**
  支持在所有已下载的内置词书和已导入的自定义词书中检索单词；精确查询未命中时会自动尝试常见英文词形还原（如从 `remained` 匹配到 `remain`）。在学习、回顾与查词结果页面中，带蓝色虚线下划线的英文单词（3 个字母以上且非当前词头）均可直接点击连续速查，查完后可一键返回原学习或回顾位置并恢复焦点。
- **单词快闪（Word Flash）**
  在「今日」页面底部（含每日完成摘要下方）提供随机抽词快闪卡片，综合待巩固词、已学词、未学词及其他已缓存词书按权重抽取词汇；支持按钮翻页与触屏左右滑动切换，支持英/美发音试听，点击单词标题可直达完整词条详情。
- **分类回顾与错词巩固**
  按「巩固 / 已学 / 未学」分类管理词汇，并支持单词、音标、释义、短语、解析和词源关键词实时搜索。系统自动为错词标记「记忆模糊」或「拼写错误」标签，支持「记住了」（移出巩固）、「再学」（排入待学习队列末尾）与「不学」（从学习计划与当日队列移除）。
- **学习统计与百词测验**
  实时统计已学/目标词数、已掌握词（掌握度 ≥ 75%）、综合正确率、拼写正确率、累计拼写次数、连续学习天数以及可按月翻页的学习日历；内置「100 词学习测验」，支持从全词书或已学单词（满 100 词解锁）随机抽题测验并保留最近 5 次成绩。
- **本地优先与数据可控**
  支持自定义每日新词配额（`1–50` 词）、导入符合格式的自定义 JSON 词书、导出当前词书的学习进度备份，以及重置当前词书记录。

## 使用说明

### 1. 切换词书与顶部栏
- 点击顶部中央的**当前词书名称**即可打开词书管理弹窗，切换内置词书、导入自定义 JSON 词书或下载格式样例。
- 顶部右侧显示**连续完成天数**（完成每日全部任务后累计）。

### 2. 「今日」学习主流程
- **查词**：在页面顶部输入框中输入英文单词，按回车或点击「查询」，即可在所有已下载/已导入的本地词书中检索详情。
- **开始今日任务**：点击主按钮按顺序进入当前阶段：
  1. **近期复习**：先根据词头与音标回想中文释义，点击「显示答案」核对后，选择「认识」或「还不熟」（选「还不熟」会自动标记为记忆模糊并收入巩固列表）。
  2. **今日学习**：查看核心释义、AI/详细解析、常用短语、例句、近义/易混词与词源。底部操作栏提供四个按钮：
     - **需重温**：将当前词放到今日学习队列末尾稍后再看；
     - **很熟悉**：直接标记为已掌握，从今日学习和当日测验中移除；
     - **上一个 / 下一个**：向前或向后切换单词（点「下一个」即完成该词本次学习并推进进度）。
  3. **今日测验**：
     - **第一轮 · 认词**：根据英文选出最准确的中文含义，不确定可点击「我不知道」；选错或选不知道会显示解析并加入本轮末尾加练。
     - **第二轮 · 拼写**：根据中文释义、字符数提示与音标输入英文单词，不会可点击「不会」；拼写错误会提示正确拼写，并加入本轮加练及巩固列表。
- **完成摘要与单词快闪**：完成当日全部任务后进入「DAILY COMPLETE」摘要视图，上方保留查词框与「查看学习统计」入口；页面底部的「单词快闪」支持点击「上一词 / 下一词」（移动端支持左滑下一词、右滑上一词）进行碎片化温习，点击词头可直接查词。

### 3. 「回顾」词汇管理
- 在顶部切换 **「巩固」「已学」「未学」** 标签页，配合搜索框即时检索词头、音标、中文释义、短语、解析或词源。
- 点击任意词条即可原地展开完整详情，其中英文单词同样支持点击快速查词与朗读。
- 词条右侧操作按钮说明：
  - **巩固列表**：点击「记住了」移出巩固列表；点击「再学」排入待学习列表末尾重新学习；
  - **已学列表**：点击「再学」将其重新加入待学习列表末尾；
  - **未学列表**：点击「不学」将其从学习计划及今日待学/测验队列中跳过。

### 4. 「统计」与 100 词测验
- 查看当前词书的已学词数、已掌握词数、综合正确率、拼写正确率、累计拼写次数与完成天数。
- 通过**学习日历**查看每天新学单词数量，支持按月份切换历史记录。
- 在页面底部的 **「100 词学习测验」** 中，可选择「从全词书抽 100 个」或「从已学习的单词抽 100 个」（需当前词书或已学词数满 100 词），每题 1 分、满分 100 分，完成后记录最近 5 次成绩。

### 5. 「计划」与数据备份
- **每日新词数量**：点击 `− / +` 可在 `1–50` 词之间调整（默认 `20` 词），修改后从下一次生成当日任务起生效，并同步估算预计完成日期与整本进度。
- **导入 / 导出 / 重置**：支持打开词书管理弹窗导入词书、将当前词书的学习进度导出为 JSON 备份，或重置当前词书的学习进度、测验成绩与每日记录。

### 6. 语音播放与离线使用
- **单词发音**：音标旁的「英」「美」按钮调用在线词典音频（需联网）；若词书包含内嵌录音（`audioBase64`），右侧还会提供独立播放按钮（无录音数据时回退为浏览器 TTS）。
- **短语与例句朗读**：短语与例句前的喇叭按钮使用浏览器内置 `Web Speech API`（优先选择本机英语语音及美音 `en-US`），朗读期间再次点击即可停止；设备装有离线英语语音包时可离线朗读。
- **离线查词与数据安全**：已加载并缓存的内置词书及导入词书支持离线查词（未打开过的内置词书需先在联网时切换一次以完成下载和索引）；由于所有学习数据仅存于当前浏览器的 `IndexedDB` 中，清理浏览器数据或更换设备前请先在「计划」页导出备份。

## 自定义词书格式

在「切换单词书」弹窗中点击「下载格式样例」或参考仓库内的 [wordbook-sample.json](wordbook-sample.json) 即可编写自定义词书 JSON 后导入。核心结构如下：

```json
{
  "id": "my-wordbook",
  "name": "我的单词书",
  "description": "词阶 JSON 词书格式样例",
  "audioEncoding": "base64-mp3",
  "words": [
    {
      "id": "resilient",
      "word": "resilient",
      "phonetic": "/rɪˈzɪliənt/",
      "audioBase64": "",
      "meaning": "adj. 有韧性的；能迅速恢复的",
      "analysis": "支持 Markdown 语法与【分段标题】的详细用法解析",
      "phrases": [
        { "en": "a resilient system", "zh": "有韧性的系统；发生故障后仍能恢复" }
      ],
      "examples": [
        { "en": "She remained resilient under pressure.", "zh": "她在压力下依然坚韧。" }
      ],
      "synonyms": [
        { "word": "robust", "note": "强健稳定的" }
      ],
      "confusables": [
        { "word": "resistant", "note": "抵抗的，不等于恢复力强" }
      ],
      "etymology": {
        "root": "resile",
        "rootMeaning": "v. 弹回；恢复",
        "explanation": "来自拉丁语 resilire，字面含义是“向后跳、弹回”。",
        "cognates": [
          { "word": "resilience", "meaning": "韧性；恢复力" }
        ],
        "memory": "把它想成被压弯后仍会弹回原状。"
      }
    }
  ]
}
```

- 仅 `words` 数组及每个词条的 `word` 字段为必填，其余字段均可按需省略；
- `audioBase64` 支持纯 Base64 编码的 MP3 字符串或 `data:audio/mpeg;base64,...` 格式。

## 本地运行与测试

由于浏览器对本地 `file://` 协议的 `fetch` 存在限制，建议通过本地静态 HTTP 服务启动以完整加载内置词书：

```bash
python3 -m http.server 8000
# 在浏览器访问 http://localhost:8000
```

运行自动化回归测试套件（Node.js）：

```bash
node tests/review-regressions.cjs
```
